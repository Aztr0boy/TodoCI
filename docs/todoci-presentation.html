ทุกครั้งที่มีการเปลี่ยนแปลง

GitHub SCM→Build→Test→Deploy

Build

สร้าง venv, ติดตั้ง requirements และตรวจ syntax

Test

รัน pytest 38 tests และเผยแพร่รายงาน JUnit

Deploy

จัดไฟล์, เปิดเว็บชั่วคราว, smoke test API และเก็บ tar.gz

Deploy เป็นการจำลองใน Jenkins workspace ไม่ใช่เว็บ public

TodoCI · Mini-Project07 / 09
07 · สาธิต

Demo flow

  1. เปิดหน้าเว็บและเพิ่มงาน พร้อมกำหนดวัน/ความสำคัญ
  2. ค้นหาและกรองงาน จากนั้นเปลี่ยนสถานะเป็น doing และ done
  3. รัน `python -m pytest -q` ให้เห็นผลทดสอบ
  4. เปิด Jenkins build แสดง Build, Test, Deploy และ artifact

รันเว็บในเครื่อง: python server.py --port 3002 แล้วเปิด http://localhost:3002
